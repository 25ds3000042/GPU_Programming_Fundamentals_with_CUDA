What is a Julia Set?

A Julia set is a fractal generated from a simple mathematical equation involving complex numbers:

Z = Z**2 + c
where:
z = a complex number representing a point on the screen
c = a fixed complex constant

You repeatedly calculate the equation based on how the value behaves, you decide whether that point belongs to the Julia set

For example:

c=−0.7+0.27015i

You can calculate millions of pixels and color them according to how quickly they "escape."
